# Commut Bus Fare Checker

Internal Commut tool. Implements Rume's Event Transportation Pricing and Operating Policy as drafted.
Provisional distances must be verified.

Four modes: long distance (per km), short distance (supplier cost), multiple shuttle trips, departure check.

Single static page: `index.html`. Tests: `npm i && npm test` (needs Google Chrome; set `CHROME=/path/to/chrome` if not at /usr/bin/google-chrome).
